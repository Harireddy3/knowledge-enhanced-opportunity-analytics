# Knowledge-Enhanced Predictive Analytics for Digital Opportunity Discovery

Minimal, reproducible research repository for the short-communication study:

**A Knowledge-Enhanced Predictive Analytics Model for Identifying Digital Transformation and Innovation Opportunities**

## What this project tests

The experiment tests whether a small set of transparent, domain-informed behavioral features improves prediction of online purchase intention compared with conventional predictive baselines. Purchase propensity is treated as an **operational proxy for digital opportunity**, not as a direct measurement of firm-level digital transformation or innovation.

Dataset: UCI Online Shoppers Purchasing Intention (12,330 sessions; target: `Revenue`). The script downloads the public dataset when run.

## Run

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run_experiment.py
```

Outputs are written to `outputs/`:
- `table1_model_metrics.csv` — test-set metrics for each model
- `table2_ablation.csv` — baseline versus knowledge-enhanced ablation
- `figure1_model_comparison.png` — ROC curves
- `figure2_feature_importance.png` — permutation importance for the knowledge-enhanced model
- `results.md` — machine-generated results summary to transfer into the paper

## Models and evaluation

1. Logistic regression on standard raw predictors.
2. Random forest on standard raw predictors.
3. Random forest with additional rule-inspired, interpretable features.

A stratified train/test split is used. Preprocessing is fitted on training data only. Metrics include ROC-AUC, average precision, F1, balanced accuracy, and precision/recall. The script uses a fixed random seed for reproducibility.

## Important research integrity notes

- Run the experiment before reporting numerical findings. The repository does **not** claim results until generated by the script.
- The UCI dataset describes online shopping sessions; it does not directly measure organizational digital-transformation maturity, innovation output, or entrepreneurship. Interpret results as evidence about **digital customer-journey opportunity detection**, and narrow the paper's claims accordingly.
- This is an empirical prototype, not causal evidence that a digital intervention creates innovation or business performance.
- Cite the dataset and document the retrieval date in the final paper. Check the dataset's current terms before redistribution; the code downloads it at runtime rather than bundling the data.
